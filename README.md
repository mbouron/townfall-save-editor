# Townfall Save Editor

> This editor was entirely generated by an LLM. Unofficial tool, not
> affiliated with the developers of SILENT HILL: Townfall. **Use at your own
> risk.**

Supports SILENT HILL: Townfall, Steam build 25168814 (September 22, 2026,
Unreal Engine 5.6.1).

A browser-based save editor for **Townfall**. Everything runs client-side: no
upload, no server.

- **Inventory**: change counts, ammo and durability. Add any of the game's 335
  items, or remove items.
- **Stats**: playthrough and lifetime counters, plus achievement flags.
- **Missions**: mission and objective states (advanced).
- **All values**: search and edit every key in the save.

Supports `SaveGameSlotN.sav`, `SaveGame.sav`, `ProfileData.sav` and
`DisplaySettings.sav`. For the reverse-engineered format, see
[FORMAT.md](FORMAT.md).

## Use

1. Back up your save folder: `%LOCALAPPDATA%\Townfall\Saved\SaveGames\`
2. Open the site, drop a `.sav` file, edit it, then click **Download edited
   save**.
3. Quit the game and replace the original file. If Steam Cloud restores the
   old file, turn Steam Cloud off for Townfall while you test.

## Develop

A static site with no build step. It lives in `docs/`, so GitHub Pages can
serve it directly (Settings → Pages → branch `master`, folder `/docs`).

```sh
# Serve the site, then open http://localhost:8000
python3 -m http.server -d docs 8000
# parse → write must be byte-identical for every save in saves/
node tools/roundtrip.mjs
# inventory rewrite round-trip + edit test
node tools/test_model.mjs
```

- `docs/gvas.js`: generic UE 5.4+ GVAS reader/writer. Unknown data is kept as
  raw bytes.
- `docs/model.js`: Townfall layer (key maps, inventory).
- `docs/app.js`: UI.
- `docs/data/`: item and mission databases, extracted from the game by
  `tools/extract_gamedata.py`.
