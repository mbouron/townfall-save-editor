Townfall Save Editor

Supports SILENT HILL: Townfall, Steam build 25168814 (September 22, 2026, Unreal Engine 5.6.1).

Where are my saves?

Windows: %LOCALAPPDATA%\Townfall\Saved\SaveGames\

Linux / Steam Deck (Proton): ~/.local/share/Steam/steamapps/compatdata/1636440/pfx/drive_c/users/steamuser/AppData/Local/Townfall/Saved/SaveGames/

SaveGameSlotN.sav are your save slots, SaveGame.sav is the latest/continue save, ProfileData.sav holds lifetime stats and options, DisplaySettings.sav graphics settings.

Before you edit

  • Back up the file first. Quit the game before replacing a save.
  • Steam Cloud may put back the old copy. Turn it off for Townfall while you test, or make sure the edited file is the newest one.
  • Changing mission or objective states can break your progression. Inventory counts and stats are the safe edits.
